# Studio Regression
 
Regression feature files for the Studio user-action commands. Each command is tested against a public demo site.
 
| Command | Feature file | Site |
|---|---|---|
| Click | `click.feature` | https://the-internet.herokuapp.com/ |
| Double click | `double_click.feature` | https://demoqa.com/ |
| Right click | `right_click.feature` | https://demoqa.com/ |
